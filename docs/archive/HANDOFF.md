# Club — Handoff (индекс)

> Первый файл для любого нового чата. Пояснения — по-русски, код и строки интерфейса — по-английски.

**Club** — клиентский utility-мод для Minecraft, Fabric 1.21.1 (Yarn, Java 21), пакет `com.club`.
Меню — **Right Shift**. Свой UI-стек (`com.club.ui`: MSDF-текст + SDF-фигуры, собственные шейдеры, свой
холст, не зависящий от GUI Scale). Лицензия **MIT**.

**Состояние на 2026-07-14: `v0.1.3` собрана, НЕ залита.** Владелец сказал «ещё допилим».
Всё готовое лежит на рабочем столе (`Club v0.1.3`): jar, 7 кадров галереи, описание, changelog.
На Modrinth сейчас висит **v0.1.2**.

## Главное правило проекта

> **Проверять в игре, а не «должно работать». И не печатать число, которое прибор не может повторить.**

Этот мод дважды печатал на своей странице цифры, которые оказались ложью (0.45 мс — мерили загрузку
машины; «43 → 11 GL-вызовов» — счётчик не видел иконки). Оба раза их снимали. За цикл оптимизации **шесть
предсказаний подряд** — планировщика, обоих чатов и скептика — были опровергнуты измерением.

## Инструменты проверки (это не тесты, это отдельные программы)

| Что | Как запустить | Что делает |
|---|---|---|
| **Харнесс** | `CLUB_HARNESS=1 ./gradlew runClient --args="--quickPlaySingleplayer club-harness-world"` | Самоуправляемый клиент: 94 проверки + 25 скриншотов. Отчёт → `run/club-harness-report.txt`. **Должен быть зелёным.** |
| **Бенч** | `CLUB_BENCH=1 ./gradlew runClient` | Арена с фиксированным сидом, два плеча (GPU-bound / CPU-bound), чередование ON/OFF в одной сессии. Умеет сказать **INVALID**, а не соврать зелёным. |
| **Промо-режим** | `CLUB_PROMO=1 ./gradlew runClient -PclubCompat -PclubIris` | Сам создаёт мир, находит горы/рощу, ставит закат, гасит ванильный HUD, снимает кадры галереи. |
| **Компоновщик** | `node tools/promo/compose.mjs --all` | Собирает кадры Modrinth (Node + headless Chrome, без npm). |
| **Совместимость** | `./gradlew runClient -PclubCompat -PclubIris` | Sodium + Iris + Freecam. |

Мира `club-harness-world` может не быть: `cp -r "run/saves/Новый мир" run/saves/club-harness-world`.

## Что было сделано недавно (чтобы не переоткрывать)

- **Stage 62** — стык с ванилью: конфликты клавиш теперь **называются** (`KeyConflicts`), меню нельзя закрыть
  от себя навсегда, клавиша спринта не залипает, карточки не врут («включён, но бездействует»).
- **Stage 63** — HUD на **собственном холсте**: GUI Scale больше не меняет его размер (`90 90 90 90` на
  четырёх масштабах). Редактор — там же. Старые позиции мигрируют.
- **Item Scroll** (7 этапов) — жесты, настраиваемые привязки, свой экран. Ноль `@Inject`: только
  `@Accessor`/`@Invoker`, поэтому подраться с Sodium/REI/EMI нечем.
- **Оптимизация** (Stage 64–76) — прибор чинили **первым** (трижды). Частицы и block-entity: **−5.3%** кадра
  на обычной машине, **−8.1%** на слабой. Иконки HUD батчатся; число вызовов — факт про сцену, поэтому
  ассертится **свойство** (`iconOn < iconOff`), а не величина, и на странице мода числа нет (см. `docs/PERF.md` §3.3).
  **Культинг сущностей построен, показал −22% и УДАЛЁН** — он стирал фантомов в открытом небе.
- **Галерея** — 7 кадров, снятых в промо-мире с шейдерами. Старая («просто скрины») выброшена.

## Правила, купленные багами (нарушать = повторить баг)

1. **Запрет «на двери» ≠ запрет в действии.** Отказ от креатива стоял в регистрации хуков — и модуль всё
   равно двигал фейковые слоты. Барьер, который однажды обойдут, — это ноль барьеров.
2. **Виджеты Club коммитят на РЕЛИЗЕ, а не на нажатии.** Захват жеста, армленный на press, привязывал сам
   себя к взводящему клику.
3. **Ноль должен уметь означать «сломано».** Тест, который проходит, когда фича не сработала, — не тест.
   Сцена обязана **спросить**, иначе прогон `INVALID`.
4. **Один кадр — не тест.** Судится каждый кадр, вердикт по худшему (иконка вылезла поверх панели только
   когда моб забредал в прицел).
5. **Сравнивать два прогона нельзя.** Только чередование ON/OFF в одной сессии, парные разности.

## Быстрый старт

```bash
./gradlew build          # сборка
./gradlew compileJava    # быстрая проверка
./gradlew runClient      # дев-клиент
```

**Коммит после каждого этапа**, локально, без push (если не просили). Сообщение объясняет *почему*.
