## 1. Философия (главное правило)

Клиент должен ощущаться **дорогим, чистым, минималистичным, игровым, современным**.
НЕ должен ощущаться как лаунчер / веб-сайт / мобильное приложение / набор градиентов /
полупрозрачный прямоугольник.

При каждом решении спрашивай: **«это делает интерфейс дороже или просто добавляет деталей?»**
Если «просто добавляет деталей» — элемент удаляется. Никакого glass, никакого blur ради blur,
никаких декоративных иконок, никаких лишних подписей/путей/координат.

## 3. Цвет (Theme.java) — палитра «UI rework v2.5» (по референс-борду)

> Референс-борд — обязателен; при конфликте текста ТЗ и борда побеждает борд.

### Фон — глубина, а не прямоугольник (нейтрально-тёмный, НЕ navy)
- База `#0B111A` (`BG_1`). За окном — `#06090F` (`BG_0`). Поверхность/поповер — `#0F1624` (`BG_2`),
  фон элементов (дропдаун/кнопка/сегмент) — `#131B2A` (`SURFACE`, hover `SURFACE_HI #18212F`).
- Бордер контрола/элемента — `#1D2536` (`BORDER`).
- Окно = почти невидимый верт.градиент `BG_WIN_TOP #0C1320` → `BG_WIN_BOT #090E16` + два краевых
  объёма `GLOW_TL ~4%` / `GLOW_BR ~2.5%` (акцент-тинт). Глубину **чувствуют**, не видят. Без стекла/блюра/свечения.

### Акцент — мягкий синий, плоский по умолчанию
- `ACCENT = #7CABFF` (основной, FLAT) · вторичный `#78D7FF`. `GRAD_A/GRAD_B = #7CABFF→#78D7FF`.
- **Градиент разрешён ТОЛЬКО в двух местах:** подчёркивание активной вкладки и активный тумблер.
  Везде ещё (заливка слайдера, активный сегмент, точка активного модуля, **текст активной вкладки**) —
  ПЛОСКИЙ `#7CABFF`.
- **Градиент ЗАПРЕЩЁН на любом тексте.** Текст — белый/приглушённый. (В `ClubFont` намеренно НЕТ
  метода для градиентного текста.)

### Текст
`TEXT #F4F6FA` (основной) · `TEXT_MUTED #A6ADBB` (вторичный) · `TEXT_DESC #767E8E` (описания) ·
`TEXT_FAINT #5A6273` (неактивное) · `TEXT_GHOST` (тинт).

### Hairlines / разделители
`HAIR ~6%` (край окна, внутр.) · **`DIVIDER ~10%`** — линии 1px между секциями (ТЗ: основной 10% / внутр. 6%).

### State — только маленькая ТОЧКА, не цвет цифр
Прочность брони / HP — крошечная точка рядом с белым текстом: `STATE_GOOD #2ECC71` (≥70%) ·
`STATE_WARN #E3C66A` (≥40%) · `STATE_LOW #E06B6B` (<40%), пороги — `Theme.stateColor(frac)`.
**Цифры/буквы цветом НЕ красим.** Точки яркие, но мелкие — не перетягивают внимание.

### Контролы-заливки / радиус
`FILL_OFF #222A38` — серый тумблер OFF · `FILL_TRACK #1D2536` — трек слайдера (2px) · `FILL_SUBTLE ~5%`
— hover-wash / трек сегмента · `ON_ACCENT` — текст поверх плоского акцента. Свечения (`GLOW`) больше нет.
Радиус: окно/поповер `RADIUS 10`, боксы-контролы `RADIUS_SM 6`, мелкие заливки `RADIUS_XS 4`.

## 4. Типографика (ClubFont.java + club_*.json)

Шрифт — **Inter** (Regular/Medium/SemiBold, `assets/club/font/inter_*.ttf`). Никаких сверхтонких
начертаний; контраст между весами намеренно небольшой.

**Главное:** текст рендерится в **нативном размере** через отдельные TTF-провайдеры и **никогда не
масштабируется матрицей** — матричный скейл и есть причина «пиксельных» букв. `oversample` высокий
для качественного сглаживания.

| Роль (метод `ClubFont`) | Провайдер | Вес | Размер | Где используется |
|---|---|---|---|---|
| `drawCat` / `widthCat` | `club_cat.json` | SemiBold | 16 | заголовок панели/попапа (лёгкий letter-spacing +1px) |
| `drawTab` / `widthTab` | `club_tab.json` | Medium | 15 | вкладки-категории (Combat/Visuals/…) |
| `drawName` / `widthName` | `club_name.json` | SemiBold | 15 | имена в HUD (Target/Potion) + значения брони |
| `drawHud` / `widthHud` | `club_hud.json` | Medium | 15 | значения HUD (HP, таймеры) |
| `drawList` / `widthList` | `club_list.json` | Medium | 13 | список модулей, dropdown, кнопки |
| `drawDesc` / `widthDesc` | `club_desc.json` | Regular | 12 | описания модулей, подсказки |
| `drawSmall` / `widthSmall` | `club_small.json` | Medium | 12 | подписи/значения контролов, футер |

**Все провайдеры — `oversample 8`** (равномерное сглаживание мелкого текста).
**HUD-текст — мягкая тень** (`drawNameShadow`/`drawHudShadow`: бледная тёмная подложка +1px вместо
жёсткой ванильной тени, которая и была причиной «рваных/жирных» букв на HUD — не отсутствие SDF).
Текст меню — без тени (лежит на тёмном окне).

Центрирование по вертикали: текст рисуется сверху-вниз, поэтому `y ≈ rowCenter − size/2`
(см. офсеты в `ClubScreen`/контролах). При смене размера провайдера офсеты надо подправить.

**Как изменить размер/вес роли:** правишь только `club_<role>.json` (`size`/`file`/`oversample`).
**Как добавить роль:** новый `club_<role>.json` + пара методов `draw<Role>/width<Role>` в `ClubFont`.
Старые 9px-провайдеры (`club/club_medium/club_bold/club_title`) и Montserrat — удалены, не возвращать.

## 5. Раскладка меню (ClubScreen)

Три зоны, разделённые тонкими hairlines:
1. **Верхняя полоса категорий** `Combat / Visuals / Player / Misc` (`drawTab`, Medium 15). Активная =
   **акцентный текст + подчёркивание акцентом** (по референсу); неактивные — muted, hover — белый.
   Лого/слова «Club» нет — пусто слева норма.
2. **Левый рейл модулей** (~25%): `● Name`, у активного — лёгкий wash + плоская акцент-точка; яркость текста = вкл/выкл.
3. **Панель настроек** (~75%): крупный заголовок (`drawCat`), описание (`drawDesc`), hairline,
   мастер-тумблер справа в шапке, компактный блок контролов.

Окна **не** масштабируем матрицей (текст остаётся резким) — только лёгкий slide при открытии.
Закрытие — **только ESC** (стандартный `Screen`), кнопок X/свернуть нет.
Плотность: внутренние отступы поджаты (~20% меньше прежнего); `BASE_W/BASE_H` и `px()` задают сетку.

## 6. Контролы (gui/components)

Боксы-контролы (Dropdown/Button/Segmented) рисуют поверхность через единый `RenderHelper.controlSurface`
(`SURFACE` + `BORDER`) — одна компонент-семья.
- **ToggleWidget** — OFF: серая пилюля (`FILL_OFF`); ON: мягкий акцент-градиент (одно из 2 разрешённых
  мест), белый бегунок, **без свечения**.
- **SliderWidget** — трек 2px (`FILL_TRACK`), заливка **плоским акцентом**; технический бегунок 10px
  (акцент, не «шарик»); label/value белые, значение НЕ цветное.
- **SegmentedWidget** — боксированный трек; активный сегмент — **плоский акцент** (`ON_ACCENT` текст).
- **DropdownWidget** — боксированный header; значение белое/muted; акцент только на шевроне (open) и
  подложке выбранной строки (`ACCENT_FAINT`).
- **ButtonC** — бордер-аутлайн; `primary()` = акцентный текст + лёгкий акцент-wash (как «Reset» на референсе),
  обычная — muted текст.
