# Club — HUD Elements & Settings

> Всё для дальнейшей работы с **HUD** (Armor / Potion / Target), их настройками и редактором позиций.

## 1. Принципы HUD (из ТЗ)

- Без карточек/баров/рамок: ванильная иконка (или спрайт) + текст. Каждый элемент несёт функцию.
- Текст HUD — крупный и читаемый (15px), **белый/приглушённый** (цифры/буквы цветом НЕ красим).
  **Никаких градиентов** на игровой информации. Состояние — маленькой **точкой** (броня) или тонкой
  **2px линией** (Target HP), а не цветом текста.
- Тень — **мягкая** (`ClubFont.drawNameShadow`/`drawHudShadow`: бледная тёмная подложка +1px), не
  жёсткая ванильная (она давала «рваные» буквы). Читаться должно за долю секунды.

## 2. Карта кода

| Файл | Роль |
|------|------|
| `hud/HudManager.java` | регистрирует `HudRenderCallback`, рисует чёрные полосы screen-stretch, диспатчит элементы |
| `hud/ArmorHud.java` | броня: иконка слева + значение справа (или ряд ячеек) |
| `hud/PotionHud.java` | эффекты: спрайт + название + время |
| `hud/TargetHud.java` | сущность под прицелом: точка-акцент + имя + HP (одна строка) |
| `hud/HudStyle.java` | общий порог `isLow()` + поверхность поповера редактора |
| `gui/HudEditorScreen.java` | drag-расстановка + примагничивание + поповер настроек элемента |
| `config/ClubConfig.Hud` | сохраняемые настройки всех HUD |

Шрифты HUD — роли `drawName` (имена, SemiBold 15) и `drawHud` (значения/время, Medium 15) из
`ClubFont`. State-цвета — `Theme.stateColor()`. См. [DESIGN.md](DESIGN.md).

## 3. Armor HUD

- Вертикально (по умолчанию): колонка `[иконка] значение ●`; горизонтально: ряд ячеек `иконка / значение ●`.
- Значение: `407/407` (count) или `92%` (percent) — переключатель **Value** в поповере (`armorPercent`).
  **Значение — главный элемент: белое (`TEXT #F4F6FA`), SemiBold (`drawName`)**, мягкая тёмная тень.
- Прочность показывает маленькая **точка** справа (`Icons.dot` + `Theme.stateColor`): `#2ECC71` (≥70%),
  `#E3C66A` (≥40%), `#E06B6B` (<40%). Точка мелкая, не перетягивает внимание. Цифры цветом НЕ красим.
- Пустые слоты пропускаются. Превью в редакторе — алмазная броня с разной прочностью.

## 4. Potion HUD

- Строка эффекта: `[спрайт] Название  Время`. Колонка (по умолчанию) или ряд (`potionHorizontal`).
- **Иерархия: название — самое заметное (`TEXT`, SemiBold `drawNameShadow`), время — светло-серое
  (`TEXT_MUTED`, `drawHudShadow`).** Время **всегда серое** — никаких цветных букв (по ТЗ v2.5; красный
  «истекает» убран).
- Сортировка — истекающие первыми. Без градиентов, без цветного текста.

## 5. Target HUD

- Две строки + линия: `Имя` (белое, SemiBold `drawNameShadow`) сверху, `18.6 HP` (muted `drawHudShadow`)
  ниже, и одна тонкая **2px HP-линия** по фракции здоровья — **единственный** акцент.
- Имя и HP — **без градиента, без цветного текста.** HP-линия — акцент `#7CABFF`, при <30% → `STATE_LOW`.
  Длинное имя обрезается до 18 симв. (Голова/аватар с референса — это пример-иконка, намеренно НЕ рисуем.)
- Автопозиция справа от прицела, пока не перетащили (`targetX/targetY = -1`). Дальность детекта —
  `targetDistance` (3–32, raycast в `raycastTarget`).

## 6. HUD Editor (gui/HudEditorScreen)

- Открывается из меню **Misc → HUD Editor → Open Editor**.
- Перетаскивание элементов с примагничиванием к краям/центрам (направляющие — акцент-цвет).
- Клик по элементу → плавающий поповер с его настройками:
  - **Enabled** (вкл/выкл элемент), **Size** (scale 0.5–2.0),
  - Armor: **Orientation** (Vertical/Row) + **Value** (% / Count),
  - Potion: **Orientation** (Column/Row),
  - Target: **Range** (3–32 блока).
- Все изменения сразу пишутся в конфиг. Заголовки/подписи поповера — плоский белый текст (без градиента).

## 7. Настройки (ClubConfig.Hud)

`armor / potions / target` (вкл) · `armorPercent` · позиции `armorX/Y`, `potionX/Y`, `targetX/Y`
(−1 = авто) · `targetDistance` · скейлы `armorScale / potionScale / targetScale` (независимые) ·
`armorVertical` · `potionHorizontal` · `hideVanillaEffects` (скрыть ванильный оверлей эффектов).
Миграция старого глобального `scale` → три раздельных скейла (см. `ClubConfig.migrate`, v3).

## 8. Как добавить новый HUD-элемент

1. Новый класс в `hud/` по образцу: `render(ctx)` (рисует от настроенной позиции/скейла через
   `ctx.getMatrices().push/translate/scale`), `size(...)`/`sampleSize(...)` (габариты для редактора),
   `drawSample(ctx)` (превью без живых данных).
2. Поля позиции/скейла/опций — в `ClubConfig.Hud` (+ дефолты, при необходимости bump `version` и ветка в `migrate`).
3. Диспатч — в `HudManager` (`if (cfg.hud.<flag>) NewHud.render(ctx);`).
4. Регистрация в редакторе — добавить id в `HudEditorScreen` (`box()`, `HUD_NAME`, `buildPopover`).
5. Текст — только роли `drawName`/`drawHud`, цвета — `Theme`. Без градиента на данных.
