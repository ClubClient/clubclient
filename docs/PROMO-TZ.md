## 1. Задача и почему предыдущая попытка провалена

**Задача:** сделать галерею для страницы Modrinth — картинки, которые **заставляют нажать
Download**. Это витрина продукта, а не отчёт об изменениях.

**Что было сделано и отвергнуто** (`docs/gallery/*.png`, генератор `tools/gallery.ps1`):
кадр из игры 1920×1080 + под ним фирменная панель с заголовком и врезкой.

**Дословный фидбек владельца:**
1. > «это просто скрины. нужны картинки дизайнерские красивые живые которые привлекают скачать»
2. > «на скринах видно обычный мир или хотбар, это зачем вообще нужно, это же мусор»

**Разбор:**
- Кадры сняты в dev-мире: **плоская зелёная равнина, толпа мобов, ванильный хотбар, ванильный
  счётчик FPS**. Это визуальный мусор — он не продаёт, он отвлекает и выглядит дёшево.
- Композиция «скрин + подпись» = отчёт, а не реклама. Интерфейс на кадре мелкий, в миниатюре
  галереи не читается.
- Галерея должна продавать **сам мод** (что он умеет), а не список фиксов 0.1.1.

## 2. Требования к результату

### Обязательно
- **6 картинок, 1920×1080 PNG**, кладутся в `docs/gallery/` (перезаписывают текущие).
  Первая — featured (обложка).
- **Никакого ванильного мусора в кадре:** нет хотбара, нет полосок здоровья/еды, нет ванильного
  счётчика FPS, нет толпы мобов, нет плоской равнины.
- **Интерфейс Club — герой кадра.** Он должен быть крупным и читаемым **в миниатюре**
  (Modrinth показывает галерею мелкими карточками — если в превью ничего не разобрать, картинка
  бесполезна).
- **Крупная типографика:** заголовок 70–90px, одна мысль на кадр. Набирать **настоящим шрифтом
  мода** — `tools/fonts/inter_*.ttf` (внутри реально **Onest**, семейства: `Onest`,
  `Onest Medium`, `Onest SemiBold`; грузить через `PrivateFontCollection`).
- **Единая серия:** одна сетка, одна палитра, один приём. Не шесть разных дизайнов.
- Каждая картинка = одна фича: что мод даёт игроку.

### Палитра (из `docs/DESIGN.md`, это же токены в `ClubDark.java`)
```
ink        #05080D / #0B111A      surface #0F1624      line #2A3550
textHi     #F4F6FA   text #A6ADBB   faint #5A6273
accent     #7CABFF   (плоский, единственный)          accent2 #78D7FF
good       #2ECC71
категории: combat #C9808A · visuals #9E8BD9 · player #7FBFA6 · misc #8C9BB5
```

### Что можно в промо, но НЕЛЬЗЯ в самом UI
Внутри мода запрещены glow/glass/градиенты (владелец это фиксировал жёстко). **В промо-арте
можно и нужно**: виньетка, мягкое свечение (bloom) за панелью, тень/ореол, градиентная подложка.
Промо-иконка (`build.gradle` → `genPromoIcon`) уже использует градиент — прецедент есть.

## 3. Как получить ЧИСТЫЕ кадры (главная работа)

Кадры берутся из **встроенного ин-гейм харнесса** — он уже есть и работает.

**Запуск:** `CLUB_HARNESS=1 ./gradlew runClient --args="--quickPlaySingleplayer <world>"`
Пишет `run/screenshots/club-*.png` (16 шт.) + отчёт `run/club-harness-report.txt`.
Файл: `src/main/java/com/club/harness/ClubHarness.java`. Сейчас: **39/39 проверок проходят.**

**Что нужно добавить в харнесс — сцены специально для промо** (например, гейт по отдельной
переменной `CLUB_PROMO=1`, чтобы не ломать обычный прогон):

1. **Убрать ванильный HUD:** `mc.options.hudHidden = true` (это то же, что F1) — уберёт хотбар,
   здоровье, счётчик предметов. Наш HUD рисуется через `HudRenderCallback`, который при
   `hudHidden` тоже пропускается (см. `HudManager.init`) — **это надо обойти**, если нужен кадр
   с нашим HUD, но без ванильного: снять проверку `mc.options.hudHidden` на время промо-съёмки
   (флаг в `HudManager`) — иначе получишь пустой кадр.
2. **Убрать наш FPS-чип** там, где он не к месту: `ClubConfig.get().hud.info = false`.
3. **Красивая сцена вместо равнины.** В одиночной игре можно слать команды:
   `mc.player.networkHandler.sendChatCommand("time set 13000")` (закат),
   `sendChatCommand("weather clear")`, `sendChatCommand("tp @s <x> <y> <z>")`,
   `sendChatCommand("gamemode spectator")` — если в мире включены читы. **Проверить, включены ли.**
   Если нет — **создать новый мир под промо** (можно сгенерировать из кода или подготовить руками
   и положить в `run/saves/`), выбрать живописное место: горы, вода, закат, лес.
   Мир `run/saves/Новый мир` — dev-мир владельца, **его не трогать и не коммитить**
   (харнесс работает на его копии `club-harness-world`, которая удаляется после прогона).
4. **Ракурс:** задать `mc.player.setYaw/setPitch` и позицию, чтобы фон был выразительным
   (горизонт, объём), а не «стена травы».
5. **Спрятать мобов:** в промо-мире их быть не должно (`/kill @e[type=!player]`, `difficulty peaceful`).

**Итог этого шага:** новый набор исходных кадров, где в кадре только мир + интерфейс Club.

## 4. Композитор

`tools/gallery.ps1` — рабочий генератор (PowerShell + `System.Drawing`), **его переписать**.
Черновик новой концепции: `tools/promo.ps1` — **НИКОГДА НЕ ЗАПУСКАЛСЯ, не проверен**, но там уже
готовы: виньетка (`PathGradientBrush`), bloom, квадратичный ореол за панелью (закон из самого мода),
трефоль-логотип из кода, чипы, ручной перенос строк, загрузка шрифта. **Использовать как заготовку,
но проверить каждую строку.**

**Грабли PowerShell 5.1 (уже наступали, не повторять):**
- Скрипт **обязан быть UTF-8 с BOM**, иначе тире/стрелки превращаются в «умные кавычки» и файл не
  парсится. Записывать так:
  `[System.IO.File]::WriteAllText($p, $c, [System.Text.UTF8Encoding]::new($true))`
- Переменные **регистронезависимы**: `$CAT` и параметр `$cat` — это одна переменная. Именовать
  таблицы уникально (`$HUES`).
- Вызов метода в аргументе команды надо оборачивать: `Tracked $g $($s.ToUpper()) ...`, иначе parse error.
- Трекинг (letter-spacing) в `System.Drawing` отсутствует — рисовать по букве (функция `Tracked`).

**Концепция композиции (утверждать у владельца ДО массовой генерации — показать 1 кадр):**
слева блок типографики (лого + надзаголовок + крупный заголовок + строка описания + чипы фич),
справа — **интерфейс Club, вырезанный и увеличенный**, приподнятый над затемнённым миром на ореоле,
может уходить за край кадра. Фон — мир, задавленный до 15–20% яркости + виньетка + мягкое
пятно акцентного света за панелью.
